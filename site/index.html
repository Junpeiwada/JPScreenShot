macOS メニューバーアプリ

撮った画像も、
中の文字も、同時に手に入る。

画面の文字は焼き込まれたピクセルで、コピーできない PDF やアプリでは選択すらできない。 JPScreenShot は範囲を 1 回ドラッグするだけで、画像と OCR テキストの両方を用意する。 どちらを使うかは、結果を見てから決めればいい。

待たずに、選べる

キャプチャした瞬間に画像が出る。テキストは OCR が終わり次第、同じウィンドウに埋まる。認識を待っている間も操作は止まらない。

クリックで、すぐ選択

メニューバーのアイコンをクリックすると、メニューを開かずに範囲選択が始まる。ドラッグして離せばキャプチャ完了。

テキストは直せる

認識結果はそのまま編集できる。誤認識を直してからコピーすればいいので、OCR の完璧さに頼らずに済む。

結果は閉じるまで残る

ウィンドウは勝手に消えない。見比べたり、貼り付け先を用意したりしてからコピーできる。閉じるのは「閉じる」ボタンか Esc。

モードを合わせると、27.3 ポイント変わる

同じコードのスクリーンショットを、それぞれのモードで読ませた実測値。

100% 日本語の文章（28pt / 11pt）— 完全一致
97.0% コード — コードモードで認識
69.7% コード — 日本語モードで認識

コードモードは日本語を候補から外すことで、l が 1 に化ける、&& が 88 になる、括弧が全角になる、といった誤りを防ぐ。 残るのは O と 0 のような字形の混同で、これは意図的に自動補正していない。文脈なしにどちらが正しいかは決められず、直そうとすると正しい文字を壊す。結果ウィンドウで直せる前提で、機械的な推測はしない。

画像もテキストも、外に出ない

OCR は Vision.framework によるオンデバイス処理で、通信は一切発生しない。 キャプチャした画像がディスクに書き込まれるのは、「保存」を押したときだけ。

初回のキャプチャで画面収録の権限を求められる。これは画面の内容を読むアプリに macOS が要求するもので、 システム設定 → プライバシーとセキュリティ → 画面収録 からいつでも確認・取り消しができる。

  • 外部サービスへの送信なし。アカウント登録も不要
  • サードパーティ製ライブラリへの依存なし
  • Apple の公証済み。ソースは GitHub で公開
  • 更新は Sparkle 経由。配信物は EdDSA 署名で検証される
