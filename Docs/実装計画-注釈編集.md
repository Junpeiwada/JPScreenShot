## 概要

結果ウィンドウの画像欄を「描き込めるキャンバス」にし、矢印・線・四角・円・テキスト（袋文字）・ぼかし・モザイクをベクトルのオブジェクトとして描けるようにする。描いた後もクリックで選び直して移動・変形・スタイル変更ができる。コピー・保存は描き込んだ画像を出力する。

- **対象**: 結果ウィンドウ（[ResultView.swift](../Sources/UI/ResultView.swift) の画像欄）と、画像のコピー・保存（[ResultViewModel.swift](../Sources/UI/ResultViewModel.swift)）
- **やらないこと**: ウィンドウを閉じた後の再編集（PNG への編集情報の埋め込み・専用書類形式）、テキストの座布団（背景）、ぼかし範囲を OCR から除外すること、キャンバスでの `⌘C`（オブジェクトのコピー）
- **関連**: [注釈編集_画面構成案.md](注釈編集_画面構成案.md)（画面構成・操作・決定事項）、[要求仕様.md](要求仕様.md) 4.3、[実装計画-HDR.md](実装計画-HDR.md)（別台帳）

## 設計の要点

全フェーズで守る前提。実装中に変えるならここを直してから変える。

### 座標系

- 注釈の座標は**画像のポイント座標**（`CaptureResult.pointSize` の空間、左上原点・y 下向き）で持つ。ピクセルでも画面座標でもない
- 画面表示では「表示倍率 = 表示サイズ ÷ pointSize」を掛ける（等倍なら 1）。書き出しでは `capture.scale` を掛けてピクセルにする
- 線の太さ・文字サイズ・影の距離もポイントで持つ。縮小表示中は一緒に縮んで見える（仕上がりと同じ見た目）

### 描画は 1 か所

- 画面表示とコピー・保存の書き出しは**同じ描画関数**（`AnnotationRenderer`）を通す。画面と出力で見た目がずれないようにするため
- 重なり順は **元画像 → ぼかし・モザイク → 図形・テキスト** で固定。配列の中では層ごとに順序を持ち、「前面へ／背面へ」は同じ層の中だけで動かす
- ぼかし・モザイクは**常に元画像から**その範囲を計算し直す（Core Image の `CIGaussianBlur`（`clampedToExtent` で端の黒ずみを防ぐ）／`CIPixellate`）。結果は注釈ごとに範囲と強さをキーにしてキャッシュする

### 状態と取り消し

- `AnnotationDocument`（`@MainActor @Observable`）が注釈の配列・選択中の ID・取り消し履歴を持つ
- 取り消しは**配列のスナップショット**を積む方式。ドラッグ中は積まず、ドラッグ開始時に 1 回だけ積む
- `⌘Z` はメインメニューの「取り消す」から First Responder に届く `undo:` / `redo:` をキャンバスが受ける。SwiftUI の `.keyboardShortcut("z")` は使わない（OCR テキスト欄の取り消しを奪うため）

### ビューの構成

- キャンバスは AppKit の `NSView`（`AnnotationCanvasView`、flipped）で作り、`NSViewRepresentable` で `ResultView` の画像欄に置く。マウスのドラッグ・ダブルクリック・キー入力・ポップオーバーの位置決めを細かく扱う必要があるため
- テキストの編集中だけ、キャンバスの上に `NSTextView` を重ねる
- 詳しい設定は `NSPopover`（中身は SwiftUI）を選択中オブジェクトの枠に合わせて出す

### 並行処理

- 注釈のデータ型は `Sendable` な値型（`struct` / `enum`）。描画・ドキュメント・ビューはすべて `@MainActor`
- Core Image の処理はメインスレッドで同期実行してよい（範囲は小さく、キャッシュが効く）。重ければフェーズ5で見直す

## 注意点

- **`⌘Z` の行き先**: キャンバスとOCRテキスト欄のどちらにフォーカスがあるかで取り消しの対象が変わる。First Responder の `undo:` で受ければ自然に分かれる
- **`Esc` の取り合い**: 今は「閉じる」ボタンの `.cancelAction` が `Esc` を受けている。キャンバスが先に受けて、使わなかったときだけ閉じるようにする
- **縮小表示中の当たり判定**: マウス座標は表示倍率で割ってから注釈の座標と比べる。ハンドルの大きさは画面上で一定（表示倍率に依らない）にする
- **ぼかしの端**: `CIGaussianBlur` は範囲の外側を透明として扱うため、そのままだと縁が暗くなる。`clampedToExtent()` してから元の範囲で切り抜く
- **メモリ**: Retina の大きな画像では Core Image のキャッシュが重くなる。ウィンドウを閉じたら必ず解放する（今の `windowWillClose` の方針に合わせる）
